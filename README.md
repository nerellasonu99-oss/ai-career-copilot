# AI Career Copilot

AI Career Copilot is a professional career-planning web app that helps users identify skill gaps, compare their profile to target roles, and follow a structured roadmap toward job readiness.

## Features
- Skill-gap analysis
- Career readiness scoring
- Roadmap planning
- Professional dashboard UI
- Responsive design

## Run locally
Open `index.html` in a browser.

## Tech stack
- HTML
- CSS
- JavaScript

## Project status
This project is a front-end prototype and UI concept for an AI-powered career guidance experience.
